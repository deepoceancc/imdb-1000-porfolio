Data cleaning and analysis of 1000 IMDb movies using Python (pandas & matplotlib)
# IMDb 1000 Portfolio

## Overview
This project analyzes the top 1000 movies from IMDb. It includes data cleaning, summary statistics, and visualizations to explore movie ratings, genres, and box office performance.

## Project Structure
- `data/` – Raw datasets (CSV files)  
- `output/` – Charts and summary statistics generated from the data  
- `scripts/` – Python scripts for data processing and plotting  
- `README.md` – Project description

## Key Features
- Summary statistics of movie ratings and revenue  
- Visualizations:  
  - Rating distribution (`rating_distribution.png`)  
  - Top grossing movies (`top_grossing.png`)  
- Cleaned and organized datasets ready for analysis

## How to Run
1. Open the scripts in the `scripts/` folder.  
2. Ensure all CSV files are in the `data/` folder.  
3. Run the scripts to generate charts in the `output/` folder.
